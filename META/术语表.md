## 🎯 特殊表述规则

### 复合名词翻译

#### 形容词 + 名词
- "context-conditioned PPO" → "上下文条件的PPO" 或 "上下文条件PPO"
- "learned-context Meta-PPO" → "学习上下文Meta-PPO"
- "fixed-partition Manager" → "固定分区管理器"
- "heuristic partition" → "启发式分区"

#### 介词短语
- "in-distribution tasks" → "分布内任务"
- "out-of-distribution tasks" → "分布外任务" 或 "OOD任务"
- "at episode boundaries" → "在情节边界处"
- "on independent scenarios" → "在独立场景上"

#### 短语和习语
- "tie breaking" → "并列打破" 或 "打平规则"
- "resource budget" → "资源预算"
- "feasible action" → "可行动作"
- "side effects" → "副作用" 或 "附带效果"

### 首字母缩写词处理

#### 保留原样（通常是算法名称）
- PPO, RSMA, SDMA, HRL, CSI, SINR, QoS, ULA, LoS, OOD

#### 第一次出现时给出中文解释
```python
# 原文：
# RSMA (Resource Sharing Multi-Access) allocation

# 翻译：
# RSMA（资源共享多址）分配
# 或：
# RSMA资源共享多址分配
```

### 参数和变量名处理

#### 参数类型注解
```python
# 原文：
def function(users: int, antennas: int) -> NDArray[np.float64]:

# 翻译（只翻译docstring，不翻译代码）：
"""
参数：
- users: 用户数量
- antennas: 天线数量
"""
```

## 📏 翻译风格指南

### 1. 保持简洁
- ❌ "这是用来计算Jain公平性指数的函数，它定义了全零的情况为零。"
- ✅ "返回Jain公平性指数，将全零情况定义为零。"

### 2. 主动语态优先
- ❌ "被管理器选择的分区"
- ✅ "管理器选择的分区" 或 "由管理器选择的分区"

### 3. 术语一致性
- 如果docstring中使用了"管理器"，不要在另一个地方用"经理"
- 使用上表中的推荐术语

### 4. 保留英文缩写
- PPO, RSMA, CSI等技术缩写应保留
- 第一次出现时可以给出完整英文或中文解释

### 5. 保留代码相关内容
- 函数名、类名、参数名保持英文不变
- 只翻译注释和docstring

### 6. 中英混用的规则
```python
# 可接受：
# """Configure context-conditioned PPO across a finite reproducible task set."""
# 译："""在有限可重复任务集上配置上下文条件的PPO。"""

# 保留原英文docstring的方式（可选）：
# """在有限可重复任务集上配置上下文条件的PPO。
# 
# Configure context-conditioned PPO across a finite reproducible task set.
# """
```
